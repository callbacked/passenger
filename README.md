# passenger

an interesting experiment: youtube and twitch played through a canvas in the browser, with a cloudflare worker doing the fetching. everything is typescript.

## run it locally

needs node 22.18 or newer and npm. for the browser tests, also `npx playwright install chromium`.

```sh
npm ci
npm run dev
```

open http://localhost:8787. the first run downloads and verifies the player assets, bundles `web/` into `public/`, and writes random local secrets into the ignored `.dev.vars` file.

## commands

- `npm run typecheck` generates the cloudflare runtime types and checks the worker, tests, browser code and smoke script
- `npm test` runs the unit tests
- `npm run smoke` plays real videos in a headless browser against the dev server (sign-in must be off)
- `npm run check` does all of the above plus a dry-run deploy bundle
- `npm run deploy` builds and deploys
- `npm run db:generate` writes a migration after you change `src/db/schema.ts`; `npm run db:migrate` applies migrations to the remote database, `npm run db:migrate:local` to the local one

## deploying

this checkout deploys through a wrangler profile named `personal`, so it can live next to another cloudflare login. on a new machine:

```sh
npx wrangler auth create personal
npx wrangler auth activate personal .
```

to run your own copy, change `account_id` in `wrangler.toml`, create your own kv namespace and d1 database, point the bindings at them, then:

```sh
npx wrangler secret put MEDIA_SIGNING_SECRET   # any 32+ random characters
npx wrangler secret put BETTER_AUTH_SECRET     # same
npm run db:migrate
npm run deploy
```

## sign-in (optional)

the player is open to anyone with the address until google sign-in is configured. to turn it on:

1. create a google oauth client (web application) with these redirect uris: `https://<your host>/api/auth/callback/google` and `http://localhost:8787/api/auth/callback/google`
2. put the client id in `wrangler.toml` under `[vars]` as `GOOGLE_CLIENT_ID`
3. `npx wrangler secret put GOOGLE_CLIENT_SECRET`, then `npm run deploy`

locally, put `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` in `.dev.vars`. `AUTH_DEV_PASSWORD=true` there enables email and password sign-in for browser tests without google.

a screen without a keyboard signs in by showing a qr code: scan it with a phone, sign in with google, approve.

## youtube account (optional)

**connect youtube** in the sidebar pairs a youtube account through google's tv flow: scan the qr code, approve on your phone. it unlocks your home, subscriptions, liked videos and shorts, and playback uses that session first.

## layout

- `src/` the worker (routing, media proxy, youtube and twitch providers, auth, drizzle schema)
- `web/` the browser code, bundled by esbuild into `public/`
- `public/` static assets served by wrangler
- `scripts/` build, vendoring and smoke test
- `test/` unit tests
- `migrations/` d1 migrations generated by drizzle-kit
